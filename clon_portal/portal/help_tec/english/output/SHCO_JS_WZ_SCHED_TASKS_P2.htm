Setting the schedule parameters

Description

Use this form to access the parameters of the tasks in box.

Steps

To so:

  1. To edit a record, click the button, and to create a new one, enter the following required information:
    • Task ID and name
    • Parameter
  2. Enter the following optional information:
    • Parameter value.
  3. Click the navigation buttons on this page to save the configuration.
