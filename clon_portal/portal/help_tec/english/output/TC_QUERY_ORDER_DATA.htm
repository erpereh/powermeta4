Sorting data

Description

Another possibility provided by the application is to sort the query results. You can sort the data by different fields, up to five, and establish an ascending or descending order.

Steps

To so:

  1. In Sort Data, select the field by which you want to set the first sort and indicate whether the order is ascending or descending. Repeat this operation if you want to sort the data by other fields.
  2. Click the navigation arrows or the next steps to continue with the design.
