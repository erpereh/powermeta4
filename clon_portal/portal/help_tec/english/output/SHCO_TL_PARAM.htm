Personalise the options of the work session

On the Options page, you can personalise the view mode for PeopleNet information during work sessions. In the main menu, select the Tools | User Options option in the menu bar. The User Options page opens.

There are four options:

  • Date format: use this option to specify the way in which you want to view the date values during the work sessions.
  • Style sheets: use this option to choose another style sheet in the work sessions. The style sheets determine the aspect of the application's pages. Therefore, they determine the colours, icons, fonts, and so on.
  • Do not show warnings and informative messages. You can choose to remove the warnings and informative messages that appear when working with PeopleNet. For example, before you delete a record from the application, PeopleNet shows a message asking for confirmation of your action. Use this option to remove these messages.
  • Confirm saved data during navigation. Pages that have various forms (so-called wizards), contain a number of options that allow you to save the data and navigate to another form on the page. If you select this option, messages will appear in cases in which you might lose your data. This may occur because of data errors or if you try to navigate from one form to another without previously saving the data you changed. If you do not choose this option, you will lose your data in those occurrences.

When you finish personalising the options, click the Save button. Keep in mind that to apply the new values, you must exit the application and start it again. To do so, click Logoff in the top-right part of the window.
