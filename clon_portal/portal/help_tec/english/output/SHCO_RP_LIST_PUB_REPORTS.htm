Query

Use this tool to design your own simple queries, edit queries designed previously, run published simple and advanced queries, and run published graphs and reports.

The advanced queries cannot be created, duplicated, edited, nor published with this tool. These tasks must be carried out in User Tools | Queries.

Remember that a simple query is basically any job with scenarios and a small number of defined attributes. The advanced queries work directly with the tables and may have more attributes defined than the simple ones.
