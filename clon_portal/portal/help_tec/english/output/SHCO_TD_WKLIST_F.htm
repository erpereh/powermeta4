To Do List

Description

The To Do List page shows all of the tasks assigned to you as part of a work flow process or the tasks that you have assigned. Use this page for direct access to edit the tasks that you have assigned; view, modify, or delete your personal tasks.

  • Assigned tasks

    • If in PeopleNet Ksystem you define a work flow to make a process easier to perform, you can automatically assign certain tasks to the user as part of the work flow process. These tasks will appear in the Assigned Tasks list. As a user you cannot modify the task's definition, but you can, within the To Do List page, click the Run button to carry it out.

  • Personal To Do List

Personal tasks are those that are defined by the user. You can define specific tasks that must be carried out in PeopleNet or simply reminders of work pending. You can manage personal tasks in the following ways:

  • Carry out a task: If the defined task is a process run in PeopleNet, click the button that corresponds to that particular task. The page opens in which you can start to carry out the task.
  • Modify the definition of a task: to modify the definition of a task, click the name of the task in the Personal Tasks table. The Manage Personal Tasks page opens in which you can modify the characteristics and the description of the task. For more information, see Modifying and existing personal task.
  • Delete a task: to remove a task from the Personal Tasks list, click the Delete button that corresponds to the task.
