Dynamic Filter

Description

Use this form to establish the information required to run a dynamic or runtime filter.

To so:

  • Indicate the node on which you want to apply the filter in the Criteria list.

    • Given a Meta4Object, the associated nodes with a dynamic filter are listed in Criteria. For each of these nodes you can establish a statement through the HTML filter.

    When you access the dynamic filter through the Advanced Filter link in a list, the criteria is not generated because the filter is applied to the node or table with which you are working.

  • Select the scenario with which you want to work when filtering.

    • Only the scenarios whose base table coincides with the base table of the node whose filter you are editing are listed. If you do not make this selection, you will work with the node's base table.


  • Define the filter conditions that you want to establish. The following options are available to do so:
    • Enter the filter directly through the Filter button.

      • For more information on editing the HTML filter, see Defining the HTML filter.


    • Use a filter defined beforehand by clicking Predefined Filters. A list is displayed with the filters that you designed beforehand with your user and for the selected scenario, or for the base table associated with the node if you did not indicate a scenario. Select the filter that you want to apply. You are automatically taken back to the main dynamic filter editing page. For more information, see Defining predefined filters.

      • The text of the filter that you designed or that you selected from the predefined filters is displayed in the text box below.

  • Save the filter for the node by clicking the Save button.
  • Repeat the process for each node that you want to filter.
  • Apply the filter globally to the Meta4Object by clicking the Apply filter button.
