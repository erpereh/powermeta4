Defining the advanced options

Description

Define the currency, language, and role to be used in the box execution on this form. By default, the system uses the values of the current session. You can change these, however, in the list boxes by selecting different values for each item.

Steps

To so:

  1. Enter the following required information:
    • Execution role
    • Priority ID
    • Currency
    • Language
  2. Enter the following optional information:
    • Run queue
  3. Click the links or use the navigation buttons on this page to complete the configuration.
