Configuring the report output

Description

This form describes the steps required to configure the running or scheduling of a report.

Actions

This option provides you to possibilities:

  • Run a report directly. To do so, select the necessary options and run the report.
  • Schedule the report. Determine when you need to run the report.

    • To view the results of scheduling the running of a report, see the Executions option in the Job Scheduler.


To facilitate the task of entering parameters, the system allows you to view a window with most of the configuration options. This configuration window is divided into 3 steps.

In the first step, Output Type and Format, follow the procedure below:

  1. Select the execution type.
  2. Select the output type. The options are:
    • Viewer: allows you to view the report in the browser.
    • File on Client: the result of running the report is saved on the client machine.

      • The system displays a dialogue box that allows you to save the file to the desired location on the local disk.

    • File on Server: the file resulting from running the report is stored in the file system on the server.

      • To do so, enter the Relative Path to Temporary Report Directory on the server where the report is saved.

    • Printer on Client: the report is printed on a printer on the client machine.

      • The system displays a combo list to select the printer.

    • Printer on Server: printing is on a server printer.

      • If the selected output type is Printer on Server, the system displays the list of available printers and, once one is selected, sets the default language associated with it.


      When scheduling reports, the only output types allowed are File on Server and Printer on Server. The rest of the options are disabled.


  3. Select the output format. The formats allowed vary depending on the output type selected in the previous step:
    • HTML: allowed for the viewer and the file on server options.
    • PDF: allowed for the viewer and file options, both on the client machine and on the server.
    • Text: this format can be used in any case.
    • PCL: allowed in any type of output except the viewer.
    • ESCP: allowed in any type of output except the viewer.
    • PostScript: allowed in any type of output except the viewer.
  4. Click the links or use the navigation buttons on this page to complete the configuration. This way you can enter information related to:
    • Device Options. More information: Registering the device options
    • Advanced Options. More information: Registering the advanced options
