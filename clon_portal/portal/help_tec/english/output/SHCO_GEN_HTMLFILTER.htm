Defining the HTML filter

Description

Use this form to establish the details required to run an HTML filter.

Actions

The HTML filter allows you to run searches from the Web client by selecting the desired criteria in the user interface, and it allows you to configure and create complex criteria in the Web environment based on any table.

To so:

  1. Complete the required Detail ID field.
  2. Select whether the criteria must be met in all records or only in some of them.
  3. Select the table and the table field to which the criteria that you are establishing is applied.
  4. Indicate the type of relationship that it will have with another table, field, or value.
  5. Select:
    • Table/Field if you want the criteria to have a relationship with another table and the field. To do so, use the drop-down fields that are loaded with the corresponding data.
    • Value if you want the field to have a particular value.
  6. Select the connector type if you want to establish more filter criteria for a single field.
  7. Click the Set Detail button. The Detail appears at the bottom of the page. If you want to modify any of the data, click the Edit button.
  8. Repeat the process for each of the filter criteria.
  9. Once you have finished defining all of the details, click Save if you want to save the changes. You are asked if you want to save the filter as a predefined one. If you do, indicate a name for the predefined filter and click OK. If you do not want to define it as a predefined filter, click Cancel. For more information, see Defining predefined filters.

    10. Click Apply Filter to continue designing the dynamic filter. If you apply the changes without saving the filter, you will not have the option of saving it as a predefined filter.
