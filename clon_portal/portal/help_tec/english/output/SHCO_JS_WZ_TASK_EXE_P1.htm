Viewing the status of the executions

Description

This option explains how to view the scheduled tasks, view the execution status, edit the execution, and even cancel or abort it. There are two options for viewing the evolution of a scheduled task:

  • In Tools | Job Scheduler, use Execution option to view the status of the execution of a task scheduled previously.
  • Use Manage Executions to view the run queue filtered by specific criteria. This gives you a quick way to view the scheduled tasks and their status.

Steps

To so:

  1. To filter for the status that you want to consult, select the corresponding check boxes and click the button. Statuses include:
    • Run: the box has finished its execution.
    • Pending: execution has not yet started.
    • Running: the box is running. In other words, it has started running at least the first task in box, but there are still tasks pending.
    • Cancelling: the status prior toCancelled. Cancelling a box, will not be immediate because the task that is running at that moment will first have to finish. This status is assigned to the box while it is waiting to be cancelled.
    • Expired: if the box execution is delayed past the time defined, the box is not executed and acquires this status.
    • Interrupted: the box execution is interrupted due to reasons beyond the control of the user. For example, the server goes down. The box status will stay at Running until the server is up again. When that happens, the status will change to Interrupted.
    • Cancelled: if the run process of the box has been cancelled. Aborting a run process implies cancelling a box execution process. However, the task that is running at that moment will finish the process, but the next ones pending will not run.
    • Aborting: the status prior toAborted. When you abort a box execution, it will not be immediate. In the meantime, the box's status is Aborting.
    • Aborted: the run process of the box has been aborted. Aborting an execution means that the execution is cancelled directly. In other words, when you abort a box, all the tasks in box, including the one that is being executed, are cancelled.
  2. Select the execution that you want to consult. The Execution Details window opens.
  3. This box data is displayed for the schedule and for the tasks. The information displayed is general; it consists of the ID of the task in the box, the name, the start and end times of the execution, and so on.
  4. You can Abort or Cancel the active executions (waiting, executing, and so on). Aborting involves halting an execution that is running; cancelling is halting an execution that has not yet begun to run. These actions change the execution status automatically.
  5. Click the links or use the navigation buttons on this page to continue. This way you can view information related to:
    • Execution Parameters. More information: Query execution parameters
    • Task Executions. More information: Task Executions
    • Documents Generated. More information: Documents Generated
