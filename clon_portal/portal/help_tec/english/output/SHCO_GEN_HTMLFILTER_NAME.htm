Defining predefined filters

Description

When you design a filter that you believe you will use frequently, you can save it to use it again on other occasions.

The following process indicates how to define a predefined filter, how to use it, and how to delete it.

Steps

The life cycle of a predefined filter is the following:

  1. When you are defining an HTML filter, save it be clicking Save. This button allows you to save the filter that you just defined as a predefined filter so that you can reuse it on other occasions. On the page that is displayed, indicate a name for the predefined filter and click OK. Once you have saved the filter as a predefined filter, the next time you edit it and click Save, the predefined filter is updated automatically.
  2. Once you have created the predefined filter, you can use it through the dynamic filter and through Advanced Filter, which appears on some lists.

    3. The predefined filters that you can apply are the ones you created with your application user. The available filters are the ones whose scenario coincides with the selected one, or, if you did not establish a scenario, the ones whose base table coincides with the base table of the node selected in Criteria.

  3. There are two options for deleting a predefined filter:
    • In the definition of the dynamic or advanced filter, select the scenario and the criteria used to create the predefined filter and click Predefined Filters. On the list that is displayed, click the Delete button corresponding to the filter that you want to eliminate.
    • In the definition of the HTML filter, when you edit the filter from which the predefined filter was created, if you delete all of the details and save the changes, the application will ask you if you want to delete the predefined filter.
