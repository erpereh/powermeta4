Selecting the fields

Description

To design a query, you must indicate the fields involved in the design and those that are part of the end result. If you base your query on an existing one, you can add new fields or remove some of the existing ones.

This operation corresponds to the SELECT and FROM clauses of the SQL statement. Here you define the columns to be used to generate the output.

Steps

To so:

  1. Click Add/Remove Fields
  2. Select the table and the first field that you want to add. Click the green check mark to Add. Repeat the operation until you have selected all of the fields you need. If, for design reasons, you need to select the same field several times, the application generates a new label to tell them apart.

    3. If you want to eliminate a field, click Remove beside the field.

  3. Click Transfer to return to the query design. The design page shows all of the selected fields with their name, length, and the table to which the field belongs in the Path column. You can modify the length of the field and the literal with which the field is labelled.
  4. Deselect the fields that you do not want to display in the end results. The application selects all of the fields by default.
  5. Click the navigation arrows or the next steps to continue with the design.
