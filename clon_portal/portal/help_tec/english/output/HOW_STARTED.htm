Getting Started

The help system for this module guides you through the use of the application without taking into account its functionality.

Help on each one of the windows in the application. It provides clear and concise information on all of the processes that can be performed (How to...).

For easier understanding, each How to... is structured as follows:

  • Description

    • Objective and purpose of the process.

  • Steps

    • The steps required to perform the process. These steps are in a numeric sequence.

  • See also

    • Links that give you access to the following items:

    • Other processes or options related to the process in which you are currently located
    • Glossary of terms

The structure is hierarchical and the information is grouped as follows:

  • Tools
  • Query

Additional information on the advanced tools is also available by clicking the button. To return to the help on the functional modules in which you are interested, click this button again.
