Edit personal tasks

There are three ways to access the Manage Personal Tasks page, in which you can modify the definition of an existing personal task.

  • In the main menu page of PeopleNet, click to select a task from the Task box on the left side of the pages.
  • Choose Tasks - To Do List. Within the Personal To Do list, click on the name of the task to open the Manage Personal Tasks page.
  • Choose Tools - Modify Personal Tasks. In the filter box, select an existing personal task to open de Manage Personal Tasks page.

Use the Personal Task Management page to carry out the following process:

  • Modifying and existing personal task
  • Defining a new personal task
