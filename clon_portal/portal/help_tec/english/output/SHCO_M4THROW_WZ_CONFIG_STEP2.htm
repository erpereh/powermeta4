Registering the device options

Description

Use this form to indicate the device options for the PCL, PostScript, or ESCP output formats, if you selected one of these in the previous step. If you selected another type of output format, the options on this form are disabled.

Steps

To so:

  • If the output format is PCL or PostScript:
    1. Select the tray type.
    2. Indicate whether or not it is duplex: deactivated, emulated, or real.
    3. Set the number of copies.
    4. Specify whether or not to rotate the page.
    5. Selects the resolution.
    6. Selects the colour.
    7. Click the links or use the navigation buttons on this page to complete the configuration.
  • If the output format is ESCP:
    1. Indicate whether or not it is duplex: deactivated or emulated.
    2. Set the line feed.
    3. Indicate the X Factor.
    4. Click the links or use the navigation buttons on this page to complete the configuration.
