Tools

Use the options on the Tools menu to improve the work sessions and to customise the appearance and behaviour of the application.

  • View, modify, or delete tasks using To Do List.
  • Add, modify, or delete tasks using Edit personal tasks.
  • Change the password for your current Username. For more information, see Change the login password.
  • Customise the behaviour of the applications for the work sessions. For more information, see Personalise the options of the work session.
  • Schedule the routine tasks that you must carry out periodically in order to save time and achieve efficiency. For more information, see Job Scheduler.
  • Check your process queue and its status. For more information, see Query execution parameters.
