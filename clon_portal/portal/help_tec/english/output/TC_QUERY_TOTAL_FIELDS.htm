Setting totals

Description

For each data group defined in the previous section, you can count the number of records or calculate the maximum, minimum, average, or total of a field that is different from the one used as the grouping criteria. You can also define these operations for all data, even if it is not grouped.

Steps

To so:

  1. In Total Fields, all of the fields selected in your query are displayed, indicating the operations that you can carry out on them. The operations that you can not carry out on each field are unavailable. These restrictions are established based on each field's type.

    2. Select the operation that you want to carry out for each field.

  2. Click the navigation arrows or the next steps to continue with the design.
