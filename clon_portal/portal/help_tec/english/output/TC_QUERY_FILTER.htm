Filtering data

Description

Once you have selected the fields, you can set conditions that you want the records to meet.

This step corresponds to the WHERE clause of the SQL statement.

Steps

To so:

  1. Define the conditions that you want by clicking Edit Filter. For more information, see: Defining the HTML filter.

    2. You can also define the filter when you run the query, so you can change the conditions with each execution. To make this option available, select the Runtime Filter check box.

  2. You can add an additional condition to the filter when working with history tables. If you select the History Filter with Today's Date check box, you filter to extract the data valid on the date on which you run the query. Thus, you retrieve the data that meets the condition: start date <= TODAY >= end date.
  3. Click the navigation arrows or the next steps to continue with the design.
