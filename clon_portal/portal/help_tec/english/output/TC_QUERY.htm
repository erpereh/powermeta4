Creating simple queries

Description

This option explains the processes for creating your own simple queries, which allow you to extract the analysis data you need in the format that best suits you.

Actions

  1. Click the Queries button on the PeopleNet page header. The Published Queries page opens.
  2. The following options are available to create a query:
    • Design a completely new query. To do so, click New and, on the Scenario List, select the scenario with which you will be working for the design.

      • Remember that a scenario is a set of tables. They are created in Development Tools | Data Model | Scenario Designer.


    • Design a query based on a specific category. The advantage is that you are shown all of the scenarios associated with the category.

      • Use the filter or list to search for the category. The result of the filter is a set of records grouped by category and identified by the output type, query ID, and date last updated. Click New beside the category.


      Remember that a category allows you to classify the published queries in the web environment. They are created in User Tools | Publication Categories.


    • Take advantage of a query designed previously, duplicate it, and make any necessary changes to it. This allows you to create a query quickly, using many items while minimising the design time.

      • Use the filter or list to search for the query that you want to use as your base. The result of the filter is a set of records grouped by category and identified by the output type, query ID, and date last updated. Click Duplicate beside the query.

      You can only duplicate simple queries, and only when you have permissions to edit them.

  3. Once you have made your choice, the steps you must follow to design the query are practically identical; the process is different only in the amount of information that you must define. Click the links on this page or use the navigation buttons to complete the design. This way you can:
    • Add or remove fields. More information: Selecting the fields
    • Sort the fields. More information: Sorting the fields
    • Establish a filter. More information: Filtering data
    • Sort the data returned by the query. More information: Sorting data
    • Group the results by field. More information: Grouping the results by field
    • Total the results by field. More information: Setting totals
    • Indicate the format in which you want to see the query results. More information: Defining the output format for the query
