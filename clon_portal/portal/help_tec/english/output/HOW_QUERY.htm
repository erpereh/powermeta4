Running a query

Description

Once you have designed the queries, you can run them to obtain the data that you need. The query tool allows you to run any query for which you have permissions, both simple and advanced.

Steps

There are two ways to run a query:

  • Run it in the design process by clicking the button available on all of the query editing pages.
  • Run it from the list displayed when you use the query tool:
    1. Click the Queries button on the PeopleNet page header. The Published Queries page opens.
    2. Use the filter or the list to search for the query that you want to run. Each of the list items appears identified by the output type, query ID, the category and the most recent update date.
    3. Click the name of the query that you want to run. The query results appear according to the associated output type. If the query has a predefined Runtime output, you must indicate the output format, whether to run it on the client or the server, whether you want to schedule it, and so on.
