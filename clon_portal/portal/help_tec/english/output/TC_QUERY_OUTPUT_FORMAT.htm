Defining the output format for the query

Description

Once you have finished defining the basic elements of your query, you must identify it and determine the format in which you want to display the data: Excel, HTML, PDF, and so on.

Steps

To so:

  1. In Output Format, indicate a name for your query and, if you want, a description that will help you identify its function. Keep in mind that both the name and the description are displayed in the filters that help you locate a query.
  2. Associate the query with a publication category. Remember that the filters that help you find the queries are classified by these categories.
  3. Indicate whether you want your query to be available only to your user or whether it can be accessed freely, activating the corresponding option button: Private, Public. This security affects running, editing, and deleting. You can carry out any type of operation with a public query. You cannot carry out any operation on a private query, unless you created it.
  4. Indicate whether you want the results in PDF, Excel, or HTML. You can decide the output type when the query is run if you select the Runtime option button. This option also allows you to configure the query and set its runtime parameters: schedule it, run it on the server or on the client, view the results directly or save them to a file, print them, set the currency in which financial data is displayed, and so on. More information: Configuring the report output.
  5. Save the query. You can run it directly if you wish.
