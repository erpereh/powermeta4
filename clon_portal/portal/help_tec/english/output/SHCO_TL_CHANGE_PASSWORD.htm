Change the login password

Description

To change the password associated with the login ID, use the Change Password option in the Tools drop-down menu. If you have two login IDs, you can only change the password that is associated with the ID that you are using for the current session.

Steps

  1. In the main menu, select the Tools | Change Password option. The Change Password page opens. The current login ID appears automatically.
  2. Enter your current password.
  3. Next, enter your new password in the corresponding fields and repeat this to confirm it.
  4. Click Save.
