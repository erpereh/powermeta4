Sorting the fields

Description

Once you have selected the fields, you can change the order in which they are displayed.

Steps

To so:

  1. Sort Fields displays only the fields that you selected in the previous step to be displayed in the results when the query is run. They are displayed in the order in which they were selected and, therefore, in the order in which they will be displayed in the end. If you want to change the order, select the field that you want to move and use the icons Move Field Up and Move Field Down until it is in the position that you want.
  2. Click the navigation arrows or the next steps to continue with the design.
