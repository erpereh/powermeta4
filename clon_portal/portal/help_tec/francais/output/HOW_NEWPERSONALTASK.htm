Comment définir une nouvelle tâche personnelle

Objet

Utilisez la page Vos tâches personnelles pour éditer toutes vos tâches personnelles.

Pour en savoir plus, reportez-vous à Comment modifier une tâche personnelle.

Démarche à suivre

  1. Dans le menu principal, sélectionnez l'option Outils | Vos tâches personnelles. La page Vos tâches personnelles apparaît.
  2. Cliquez sur le bouton Nouveau. La page Tâche personnelle apparaît.
  3. Indiquez les caractéristiques de la tâche : libellé, date et heure de rappel, description.
  4. Cliquez sur le bouton Enregistrer.
  5. Si la tâche est associée à un processus de l'application, cliquez sur le lien Paramètres afin de renseigner le formulaire Paramètres.
  6. Indiquez les valeurs des paramètres spécifiques de la tâche. Quand vous avez terminé, cliquez sur le bouton Enregistrer.
