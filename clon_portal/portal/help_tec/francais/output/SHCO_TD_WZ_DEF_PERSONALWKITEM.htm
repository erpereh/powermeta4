Comment modifier une tâche personnelle

Objet

Utilisez la page Vos tâches personnelles pour éditer vos tâches personnelles. Pour en savoir plus, reportez-vous à Comment définir une nouvelle tâche personnelle.

Démarche à suivre

  1. Dans le menu principal, sélectionnez l'option Outils | Vos tâches personnelles. La page Vos tâches personnelles apparaît.
  2. Dans la liste, sélectionnez la tâche que vous voulez éditer. La page Tâche personnelle apparaît : elle inclut les détails de la tâche sélectionnée.
  3. Révisez et, au besoin, modifiez les caractéristiques de la tâche : libellé, date et heure de rappel, description.
  4. Cliquez sur le bouton Enregistrer.
  5. Si la tâche est associée à un processus de l'application, cliquez sur le lien Paramètres afin de renseigner le formulaire Paramètres.
  6. Les tâches personnelles définies comme simples rappels ne sont associées à aucun processus de PeopleNet. Par conséquent, elles n'ont pas besoin d'être paramétrées.
  7. Révisez et modifiez les paramètres spécifiques de la tâche. Lorsque vous avez fini de modifier les valeurs, cliquez sur le bouton Enregistrer.
