Vos tâches personnelles

Vous accédez à la page Tâche personnelle de trois façons différentes. De là, vous pouvez éditer vos tâches personnelles.

  • Dans la page d'accueil de PeopleNet, cliquez sur une des tâches du panneau gauche intitulé Liste des tâches.
  • Sélectionnez l'option de menu Outils | Liste des tâches. Dans la table intitulée Vos tâches personnelles, cliquez sur le libellé de la tâche de votre choix afin d'ouvrir la page Tâche personnelle.
  • Sélectionnez l'option de menu Outils | Vos tâches personnelles. La page de filtre apparaît : sélectionnez-y l'une de vos tâche, vous accédez à la page Tâche personnelle.
