Filtre dynamique

Objet

Ce formulaire vous permet de définir les informations nécessaires à l'exécution d'un filtre dynamique.

Procédez comme suit :

  • Dans la liste Critères, indiquez sur quel nœud vous souhaitez appliquer le filtre.

    • Pour un Meta4Objet donné, la liste Critères regroupe les nœuds associés au Meta4Objet possédant un filtre dynamique. Pour chacun de ces nœuds, vous pouvez définir une instruction à l'aide du filtre HTML.

    Lorsque vous accédez au filtre dynamique depuis le lien Filtre avancé d'une liste, les critères ne sont pas générés étant donné que le filtre est appliqué au nœud (ou à la table) sur lequel vous travaillez.

  • Sélectionnez le scénario sur lequel vous souhaitez travailler lors de l'exécution du filtre.

    • Seuls les scénarios dont la table de base coïncide avec la table de base du nœud dont vous éditez le filtre sont listés. Si vous ne sélectionnez pas de scénario, vous travaillez avec la table de base du nœud.


  • Définissez les conditions de filtre voulues. Pour cela, vous disposez des options suivantes :
    • Écrire directement le filtre : utilisez le bouton Filtre.

      • Pour en savoir plus sur les modes d'édition des filtres HTML, reportez-vous à Définir un filtre HTML


    • Utiliser un filtre déjà défini : utilisez le bouton Filtres prédéfinis. La liste des filtres que vous avez définis antérieurement à l'aide de votre nom d'utilisateur est affichée, pour le scénario sélectionné ou, à défaut, pour la table de base associée au nœud. Sélectionnez le filtre que vous souhaitez appliquer. Vous revenez automatiquement à la page principale d'édition du filtre dynamique. Pour en savoir plus, reportez-vous à Établir un filtre comme filtre prédéfini.

      • La zone de texte de la partie inférieure de la fenêtre contient la syntaxe du filtre que vous avez défini ou sélectionné parmi les filtres prédéfinis.

  • Enregistrez le filtre sur le nœud en cliquant sur le bouton Enregistrer .
  • Répétez la procédure pour chaque nœud que vous souhaitez filtrer.
  • Appliquez le filtre de façon globale au Meta4Objet en cliquant sur le bouton Appliquer le filtre .
