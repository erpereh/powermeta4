Comment filtrer les données

Objet

Une fois les champs sélectionnés, vous pouvez établir les conditions que les enregistrements doivent remplir.

Cette étape correspond à la clause WHERE de l'instruction SQL.

Démarche à suivre

Procédez comme suit :

  1. Définissez les conditions de votre choix en cliquant sur Éditer le filtre. Pour en savoir plus, reportez-vous à Définir un filtre HTML.

    2. Vous avez également la possibilité de définir le filtre au moment d'exécuter la requête, ce qui vous permet de modifier les conditions avant chaque exécution. Pour disposer de cette option, cochez la case Filtre lors de l'exécution.

  2. Vous pouvez ajouter une condition supplémentaire aux conditions de filtre dans les cas où vous travaillez sur des tables historiques. Si vous cochez la case Filtrer les historiques à la date du jour, les données sont filtrées de façon à extraire les données en vigueur à la date d'exécution de la requête. Les données récupérées sont celles qui satisfont à la condition : date de début <= AUJOURD'HUI >= date de fin.
  3. Cliquez sur les flèches de navigation ou sur les étapes suivantes afin de continuer la construction de votre requête.
