Documents générés

Objet

Ce formulaire permet d'afficher les documents générés lors d'une exécution.

Sont affichés les documents générés suite à l'exécution de la tâche sélectionnée. Les informations disponibles sur chaque document sont :

  • la taille du document,
  • la description du document,
  • le code de la ressource ou le nom du document.

Cliquez sur les liens disponibles ou utilisez les boutons de navigation afin de continuer la configuration.
