Comment configurer la sortie d'un état

Objet

Ce formulaire décrit les étapes à suivre pour configurer l'exécution et la planification d'un état.

Actions

Cette option offre deux possibilités :

  • Exécuter directement l'état : vous sélectionnez les options voulues et l'état est généré.
  • Planifier l'exécution de l'état : vous déterminez le moment où vous voulez que l'état soit généré.

    • Pour consulter les résultats de la planification de l'exécution d'un état, reportez-vous à l'option Exécutions dans le Planificateur de tâches. Pour en savoir plus, reportez-vous à la section intitulée Comment consulter l'état d'une exécution.


Afin de vous faciliter la saisie des paramètres, l'application vous propose une fenêtre recueillant la plupart des options de configuration. Cette fenêtre est divisée en trois étapes.

Lors de la première étape, Type et format de sortie, procédez comme suit :

  1. Sélectionnez le type d'exécution souhaité.
  2. Sélectionnez le type de sortie souhaité. Vous avez le choix entre :
    • Affichage : l'état sera affiché directement dans votre navigateur.
    • Fichier dans machine client : le résultat de l'exécution sera conservé dans le client.

      • Le système vous présente alors une boîte de dialogue vous permettant d'indiquer le chemin d'accès et le nom du fichier dans le disque local.

    • Fichier dans serveur : le fichier résultant de l'exécution sera conservé dans le système de fichiers du serveur.

      • Pour cela, vous devrez indiquer le Chemin d'accès relatif au répertoire temporaire d'états où l'état sera enregistré dans le serveur.

    • Imprimante dans machine client : l'état sera imprimé à l'aide d'une imprimante du client.

      • Le système affiche une liste combinée pour vous permettre de sélectionner l'imprimante.

    • Imprimante dans serveur : l'état sera imprimé à l'aide d'une imprimante du serveur.

      • Si vous avez choisi Imprimante dans serveur, le système vous montre la liste des imprimantes disponibles, puis, une fois sélectionnée l'imprimante désirée, il établit la langue par défaut associée à cette dernière.


      Dans le cas de la planification des états, seuls sont permis les types de sortie Fichier dans serveur et Impression dans serveur. Les autres options sont alors désactivées.


  3. Sélectionnez le format de sortie souhaité. Les formats disponibles dépendent du type de sortie sélectionné dans l'étape antérieure :
    • HTML : autorisé pour l'affichage et l'archivage dans le serveur.
    • PDF : autorisé pour l'affichage et l'archivage dans le serveur et dans le client.
    • Texte : toujours disponible.
    • PCL : toutes sorties hormis affichage.
    • ESCP : toutes sorties hormis affichage.
    • PostScript : toutes sorties hormis affichage.
  4. Cliquez sur les liens disponibles ou utilisez les boutons de navigation afin de continuer la configuration. Vous accédez aux formulaires :
    • Options de dispositif. Pour en savoir plus, reportez-vous à : Comment établir les options de dispositif
    • Options avancées. Pour en savoir plus, reportez-vous à : Comment établir les options avancées
