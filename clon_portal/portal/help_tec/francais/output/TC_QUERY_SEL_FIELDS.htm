Comment sélectionner les champs

Objet

Pour construire une requête, il est nécessaire d'indiquer quels champs interviennent dans la génération de la requête et quels champs feront partie du résultat final. Si vous partez d'une requête existante, vous avez la possibilité d'ajouter ou de supprimer des champs.

Cette opération correspond aux clauses SELECT et FROM de l'instruction SQL qui détermine les colonnes qui seront reprises lors de la génération de la sortie.

Démarche à suivre

Procédez comme suit :

  1. Cliquez sur l'action Ajouter / Supprimer des champs.
  2. Sélectionnez la table ainsi que le premier champ que vous souhaitez ajouter. Cliquez sur le bouton Ajouter. Répétez cette opération jusqu'à ce que vous ayez sélectionné tous les champs désirés. Lorsque, pour les besoins de votre requête, vous avez à sélectionner plusieurs fois le même champ, l'application génère un libellé différent pour chaque champ afin de pouvoir les différencier par la suite.

    3. Pour retirer un champ, cliquez sur le bouton Supprimer correspondant au champ à éliminer.

  3. Cliquez sur le bouton Transférer pour revenir au formulaire principal de construction de la requête. Vous visualisez maintenant sur cette page tous les champs sélectionnés pour la construction de votre requête, avec leur nom, leur longueur et, dans la colonne Chemin d'accès, la table à laquelle ils appartiennent. Vous pouvez, si vous le souhaitez, modifier la longueur ou le libellé du champ (tel qu'il apparaîtra en sortie).
  4. Désactivez la case des champs que vous ne voulez pas voir apparaître dans le résultat final. Toutes les cases sont cochées par défaut.
  5. Cliquez sur les flèches de navigation ou sur les étapes suivantes afin de continuer la construction de votre requête.
