Comment définir le format de sortie de la requête

Objet

Lorsque vous avez terminé d'établir les éléments de base de votre requête, il vous reste à identifier celle-ci et à déterminer le format d'affichage des données : Excel, HTML, pdf, etc.

Démarche à suivre

Procédez comme suit :

  1. Dans la page Format de sortie, indiquez un nom pour votre requête ainsi que, si vous le souhaitez, une brève description de sa fonction. Tenez compte du fait qu'aussi bien le nom que la description apparaissent dans les filtres et les listes pour une meilleure localisation des requêtes créées.
  2. Associez votre requête à une catégorie de publication. Rappelez-vous que les filtres et les listes utilisés pour la localisation des requêtes présentent ces dernières classées par catégories.
  3. Indiquez, au moyen du bouton d'option correspondant, si vous souhaitez rendre votre requête disponible pour tous les utilisateurs ou seulement pour votre utilisateur : sélectionnez Privée ou Publique. La sécurité choisie porte sur l'exécution, l'édition et la suppression de la requête. N'importe quel type d'opération peut être effectué sur une requête publique. En revanche, vous ne pouvez réaliser aucune opération sur une requête privée à moins d'en être le créateur.
  4. Indiquez le format de sortie des résultats de la requête : pdf, Excel ou HTML. Si vous préférez laisser le choix du type de sortie pour le moment de l'exécution de la requête, marquez le bouton d'option Lors de l'exécution. Cette option permet en outre de configurer et de paramétrer l'exécution : planification dans le temps, exécution en client ou en serveur, affichage direct ou enregistrement en fichier, impression, choix de devise pour l'expression des données monétaires, etc. Pour en savoir plus, reportez-vous à : Comment configurer la sortie d'un état.
  5. Enregistrez votre requête. Vous pouvez l'exécuter immédiatement si vous les souhaitez.
