Comment exécuter une requête

Objet

Une fois construites et conservées dans le système, les requêtes peuvent être exécutées afin d'obtenir des données. L'outil de requête vous permet d'exécuter n'importe quelle requête (simple ou avancée) pour laquelle vous avez les droits nécessaires.

Démarche à suivre

Pour exécuter une requête, vous avez deux possibilités :

  • Vous pouvez exécuter une requête depuis le processus de conception de celle-ci en cliquant directement sur le bouton disponible sur toutes les pages d'édition des requêtes.
  • Vous pouvez exécuter une requête depuis la liste qui apparaît lorsque vous activez l'outil de requêtes :
    1. Cliquez sur l'icone Requêtes situé dans le bandeau supérieur droit de la page de PeopleNet où vous vous trouvez. La page Requêtes publiées apparaît.
    2. Utilisez le filtre ou la liste présentée pour localiser la requête que vous souhaitez exécuter. Chacun des éléments de la liste apparaît identifié par son type de sortie, son code de requête, sa catégorie et sa date de dernière mise à jour.
    3. Cliquez sur le nom de la requête que vous désirez exécuter. Le résultat produit par la requête se présente alors selon le type de sortie qui lui a été associé. Si l'option Lors de l'exécution a été définie pour la requête, vous devez indiquer le format de sortie souhaité, le mode de lancement (client ou serveur), une planification éventuelle, etc. Pour en savoir plus, reportez-vous à : Comment configurer la sortie d'un état
