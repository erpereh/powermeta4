Comment établir les options de dispositif

Objet

Ce formulaire vous permet de définir les options de dispositif applicables aux formats de sortie PCL, PostScript et ESCP. Si vous avez sélectionné un autre format lors de l'étape précédente, les options de ce formulaire sont désactivées.

Démarche à suivre

Procédez comme suit :

  • Si le format de sortie choisi est PCL ou PostScript :
    1. Sélectionnez le type de plateau souhaité.
    2. Indiquez si vous souhaitez une présentation recto verso ou non : désactivé, émulé ou réel.
    3. Indiquez un nombre de copies.
    4. Indiquez si vous souhaitez une rotation de page.
    5. Sélectionnez la résolution.
    6. Sélectionnez la couleur.
    7. Cliquez sur les liens disponibles ou utilisez les boutons de navigation afin de continuer la configuration.
  • Si le format de sortie choisi est ESCP :
    1. Indiquez si vous souhaitez une présentation recto verso ou non : désactivé ou émulé.
    2. Établissez l'avancement de ligne.
    3. Indiquez le facteur X.
    4. Cliquez sur les liens disponibles ou utilisez les boutons de navigation afin de continuer la configuration.
