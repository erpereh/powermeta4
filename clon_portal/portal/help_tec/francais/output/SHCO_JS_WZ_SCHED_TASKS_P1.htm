Planificateur de tâches

Objet

Ce formulaire décrit les étapes à suivre pour configurer la planification d'une tâche.

Une tâche peut être définie comme un modèle prédéfini servant de point de départ à la définition d'un groupe d'opérations ou de tâches. Il s'agit d'un segment de code LN4 auquel est associé un ensemble de paramètres dont les valeurs ne sont pas définies. Lorsque des valeurs sont affectées aux paramètres, la tâche devient une tâche de groupe à part entière. Les tâches ont pour objet de réduire le temps nécessaire à la création d'un groupe de tâches.

Le planificateur de tâches évite la répétition de certaines tâches. Grâce à lui, un certain nombre de tâches peuvent être définies en vue d'être exécutées en différé, à un moment donné ou encore chaque fois que certaines conditions temporelles sont remplies.

Le planificateur de tâches permet de gérer l'ensemble des processus liés à la définition et à la maintenance des tâches différées.

Actions

Depuis cette fenêtre, vous pouvez soit définir une nouvelle tâche dans le système, soit éditer les informations relatives à une tâche existante.

Pour ce faire, procédez comme suit :

  1. Cliquez sur le bouton Nouveau pour planifier une nouvelle tâche ou bien filtrez par le code ou le libellé des tâches existantes, par groupe de tâches ou encore par l'utilisateur d'exécution si vous souhaitez éditer une tâche déjà planifiée. Vous avez également la possibilité de filtrer en fonction de l'état du groupe de tâches :
    • Terminé : récupère les groupes de tâches dont les exécutions planifiées sont achevées. Autrement dit, le système récupère tous les groupes de tâches n'ayant aucune exécution dans l'état En attente, Exécution en cours, Annulation en cours ou Abandon en cours.
    • Commencé : récupère les groupes de tâches dont au moins une des exécutions a déjà débuté et au moins une des exécutions n'est pas encore achevée. Le système considère non encore exécutées les exécutions se trouvant dans l'un des états suivants : En attente, Exécution en cours, Annulation en cours et Abandon en cours.
    • Non commencé : récupère les groupes de tâches dont les exécutions n'ont pas encore débuté. En d'autres termes, les groupes affichés seront ceux dont les exécutions sont à l'état En attente.

      • Cliquez sur le bouton . Renseignez obligatoirement le libellé du Groupe de tâches et le Code de la tâche.


      Un groupe de tâches correspond à une succession de tâches exécutées selon un certain ordre. Définir un groupe de tâches consiste à lui attribuer un libellé, un code d'identification, une description ainsi qu'un certain nombre de paramètres, puis à affecter des valeurs à ces derniers. Vous indiquez ensuite la tâche qui fait partie du groupe, ainsi que sa date d'exécution, que vous établissez en fonction de règles temporelles.


  2. Sélectionnez obligatoirement, parmi les options suivantes, les Règles temporelles qui déterminent à quel moment le groupe de tâches devra être exécuté :
    • Immédiat : le groupe de tâches sera exécuté dès que possible.
    • Cyclique : en fonction d'une date de début à partir de laquelle le groupe sera exécuté à intervalles réguliers et d'un nombre total d'exécutions du groupe (limité à 500 en mode cyclique). Aussi devez-vous :
      • indiquer le nombre de fois où le groupe sera exécuté. La valeur de l'option Jusqu'à est automatiquement mise à jour en fonction du nombre d'exécutions indiqué.
      • Jusqu'au : si vous activez ce bouton d'option au lieu d'indiquer un nombre d'exécutions, vous devez renseigner la date et l'heure limites d'exécution du groupe. Le nombre de fois où le groupe sera exécuté changera en fonction de la date de début et de la fréquence que vous avez indiquées.
    • Liste de dates : vous déterminez une série de dates auxquelles le groupe devra être exécuté. Vous indiquez le jour et l'heure de chaque exécution. Les dates apparaissent dans une zone de texte. Pour constituer la liste de dates, utilisez les liens fonctionnels Ajouter, Supprimer la sélection et out supprimer selon vos besoins. Les dates sélectionnées doivent toujours être ultérieures à la date du jour.

      • Une fois sélectionné le mode d'exécution, vous devez finir de définir vos règles de temps en indiquant, de manière obligatoire :

    • Code du fuseau horaire : utilisez le bouton de sélection pour choisir le fuseau horaire dans lequel le groupe sera exécuté.
    • Expire après : zone de texte dans laquelle vous indiquez la fin de la période d'effet de chaque exécution programmée. De cette manière, si une exécution n'a pas été lancée dans le délai indiqué, elle ne sera plus exécutée. Le délai d'expiration s'indique en minutes.
  3. De manière facultative, indiquez :
    • la description du groupe, destinée à en préciser la finalité,
    • l'entité ou les entités pour lesquelles les tâches seront exécutées, si vous travaillez dans un environnement multiréférentiel.

      • Vous pouvez opter pour que l'exécution s'effectue uniquement pour l'entité de votre choix ou bien, au contraire, réaliser une sélection multiple. Dans ce cas, seront générés autant de groupes de tâches que d'entités sélectionnées.


  4. Cliquez sur les liens disponibles ou utilisez les boutons de navigation afin de continuer la configuration. Vous accédez aux formulaires :
    • Options avancées. Pour en savoir plus, reportez-vous à : Comment définir les options avancées.
    • Paramètres. Pour en savoir plus, reportez-vous à : Comment établir les paramètres de la planification.
    • Exécutions. Pour en savoir plus, reportez-vous à : Comment consulter l'état des exécutions.
