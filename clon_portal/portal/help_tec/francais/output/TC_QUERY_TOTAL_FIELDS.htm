Comment définir les totaux

Objet

Pour chacun des groupes de données générés (que vous avez définis lors de l'étape antérieure), il est possible de compter le nombre d'enregistrements ou encore de calculer la valeur maximale, la valeur minimale et la somme d'un champ différent de celui utilisé comme critère de regroupement. Ces opérations peuvent être également définies pour toute autre donnée même non regroupée.

Démarche à suivre

Procédez comme suit :

  1. La page Totaliser les champs affiche tous les champs sélectionnés pour votre requête ainsi que les différentes opérations que vous pouvez appliquer à ceux-ci. Seules les opérations réalisables pour un champ sont disponibles, en fonction du type de celui-ci.

    2. Sélectionnez l'opération souhaitée pour chaque champ.

  2. Cliquez sur les flèches de navigation ou sur les étapes suivantes afin de continuer la construction de votre requête.
