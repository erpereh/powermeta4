Changer de mot de passe

Objet

Pour modifier le mot de passe associé à votre code d'identification, utilisez l'option Changer de mot de passe, située dans le menu déroulant Outils. Si vous disposez de deux codes de connexion, vous ne pouvez modifier que le mot de passe associé à celui que vous avez utilisé pour entrer dans la session actuelle.

Démarche à suivre

  1. Dans le menu principal, sélectionnez l'option Outils | Changer de mot de passe. La page Modifiez votre mot de passe apparaît. Le nom d'utilisateur que vous avez utilisé pour entrer dans l'application apparaît automatiquement.
  2. Écrivez votre mot de passe actuel.
  3. Ensuite, écrivez, dans le champ correspondant au nouveau mot de passe, le mot de passe souhaité, puis écrivez-le de nouveau pour confirmer la modification.
  4. Cliquez sur le bouton Enregistrer.
