Comment définir les options avancées

Objet

Dans ce formulaire vous définissez la devise, la langue et le rôle à utiliser lors de l'exécution du groupe. Les valeurs de la session en cours sont celles qui sont marquées par défaut. Vous pouvez cependant les modifier en utilisant les boutons de sélection qui proposent les différentes valeurs possibles pour chaque élément.

Démarche à suivre

Procédez comme suit :

  1. De manière obligatoire, indiquez :
    • le rôle d'exécution,
    • le code de la priorité,
    • la devise,
    • la langue.
  2. De manière facultative, indiquez :
    • la file d'attente d'exécution.
  3. Cliquez sur les liens disponibles ou utilisez les boutons de navigation afin de continuer la configuration.
