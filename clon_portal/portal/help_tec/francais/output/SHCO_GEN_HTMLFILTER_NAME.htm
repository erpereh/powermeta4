Établir un filtre comme filtre prédéfini

Objet

Lorsque vous définissez un filtre et que vous prévoyez que vous allez l'utiliser avec fréquence, vous avez la possibilité de l'enregistrer afin de pouvoir le réutiliser ultérieurement.

Le processus à suivre pour établir, utiliser ou encore supprimer un filtre prédéfini est expliqué ci-dessous.

Démarche à suivre

Le cycle de vie d'un filtre prédéfini est le suivant :

  1. Lorsque vous définissez un filtre HTML, enregistrez-le à l'aide du bouton Enregistrer. Ce bouton vous permet d'enregistrer dans la liste des filtres prédéfinis le filtre que vous venez de créer. Dans la page qui apparaît, indiquez un nom pour le filtre prédéfini, puis acceptez. Une fois enregistré comme filtre défini, celui-ci est ensuite automatiquement mis à jour, à chaque utilisation, grâce au bouton Enregistrer.
  2. Les filtres prédéfinis peuvent être utilisés à partir d'un filtre dynamique et du bouton Filtre avancé activé pour certaines listes.

    3. Les filtres prédéfinis que vous pouvez appliquer sont ceux que vous avez créés sous votre nom d'utilisateur et qui se rapportent au scénario que vous avez sélectionné ou, à défaut (si vous n'indiquez aucun scénario), à la table de base du nœud choisi dans Critères.

  3. Pour supprimer un filtre prédéfini, vous avez deux options :
    • Depuis la définition d'un filtre dynamique ou avancé, sélectionnez le scénario et le critère sur lesquels le filtre a été créé, puis cliquez sur Filtres prédéfinis. Dans la liste qui s'affiche, cliquez sur le bouton Supprimer correspondant au filtre que vous voulez supprimer.
    • Depuis la définition d'un filtre HTML, éditez le filtre depuis lequel le filtre prédéfini a été généré, puis effacez-en tous les détails. Enregistrez les changements : l'application vous demande alors si vous voulez supprimer le filtre prédéfini.
