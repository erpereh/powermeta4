Comment établir les options avancées

Objet

Ce formulaire vous permet d'établir les options de configuration de devise, si besoin est.

Démarche à suivre

Procédez comme suit :

  1. Cochez la case Définir la devise.
  2. Sélectionnez :
    • le code de la devise,
    • le type de change,
    • la date de change.
  3. Poursuivez le processus à l'aide des boutons de navigation.
