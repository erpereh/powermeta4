Définir un filtre HTML

Objet

Ce formulaire vous permet de définir les informations nécessaires à l'exécution d'un filtre HTML.

Actions

Le filtre HTML permet de réaliser des recherches depuis le client Web en sélectionnant des dans l'interface de l'utilisateur ou en configurant, dans l'environnement Web, des critères complexes basés sur n'importe quelle table.

Procédez comme suit :

  1. Indiquez de façon obligatoire le Code du détail.
  2. Déterminez si le critère doit être satisfait par tous les enregistrements à la fois ou par au moins l'un d'eux.
  3. Sélectionnez la table et le champ de la table auxquels le critère que vous définissez devra être appliqué.
  4. Indiquez le type de relation entre le critère et une autre table, champ ou valeur.
  5. Sélectionnez :
    • Table/Champ si vous souhaitez que le critère ait une relation avec une autre table et un champ dans cette dernière. Pour ce faire, vous disposez de champs déroulants qui se chargent à l'aide des données correspondantes.
    • Valeur si vous souhaitez que le champ ait une valeur donnée.
  6. Sélectionnez le type de connecteur au cas où vous souhaiteriez définir d'autres critères de filtre pour le même champ.
  7. Cliquez sur le bouton Définir le détail . Le détail apparaît alors dans la partie inférieure de la page. Si vous souhaitez modifier une donnée, éditez-la à l'aide du bouton Éditer .
  8. Répétez la procédure pour chacun des critères de filtre.
  9. Une fois que vous avez terminé de définir tous les détails et si vous souhaitez conserver vos modifications, cliquez sur le bouton Enregistrer. Le système vous demande alors si vous désirez enregistrer votre filtre en tant que filtre prédéfini. Si oui, indiquez un nom pour le filtre, puis acceptez. Dans le cas contraire (si vous ne souhaitez pas enregistrer votre filtre dans la liste des filtres prédéfinis), cliquez sur le bouton Annuler. Pour en savoir plus, reportez-vous à Établir un filtre comme filtre prédéfini.

    10. Cliquez sur le bouton Appliquer le filtre afin de prou suivre la définition de votre filtre dynamique. Si vous appliquez les modifications sans enregistrer le filtre vous perdez la possibilité d'enregistrer le filtre comme filtre prédéfini.
