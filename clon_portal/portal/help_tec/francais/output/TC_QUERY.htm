Comment construire une requête simple

Objet

Cette option décrit les différents processus à suivre pour créer ses propres requêtes simples permettant d'extraire des données d'analyse selon les besoins et le format voulus par l'utilisateur.

Actions

  1. Cliquez sur l'icone Requêtes situé dans le bandeau supérieur droit de la page de PeopleNet où vous vous trouvez. La page Requêtes publiées apparaît.
  2. Pour créer une requête, vous pouvez :
    • Définir une requête totalement nouvelle. Pour cela, cliquez sur le bouton Nouveau, puis, dans la Liste de scénarios, sélectionnez le scénario sur lequel vous souhaitez définir votre requête.

      • Rappelez-vous qu'un scénario représente un ensemble ou groupe de tables. Les scénarios sont définis à l'aide de l'option de menu Outils de développement | Modèle de données | Designer de scénarios.


    • Définir votre requête à partir d'une catégorie existante. L'avantage de cette option est qu'elle vous montre directement tous les scénarios associés à la catégorie choisie.

      • Utilisez le filtre ou la liste pour localiser la catégorie voulue. Le filtre affiche comme résultat une liste d'enregistrements regroupés par catégorie et identifiés par le type de sortie associé, leur code de requête et la date de leur dernière mise à jour. Cliquez sur le bouton Nouveau situé à gauche de la catégorie de votre choix.


      Une catégorie permet de classifier les requêtes publiées dans un environnement Web. Les catégories sont définies à l'aide de l'option de menu Outils de l'utilisateur | Catégories de publication.


    • Réutiliser une requête définie préalablement, en la dupliquant, puis en y apportant les modifications opportunes. De cette façon, vous créez votre requête rapidement grâce à la réutilisation d'un grand nombre d'éléments.

      • Utilisez le filtre ou la liste pour localiser la requête qui vous servira de base. Le filtre affiche comme résultat une liste d'enregistrements regroupés par catégorie et identifiés par le type de sortie associé, leur code de requête et la date de leur dernière mise à jour. Cliquez sur le bouton Dupliquer situé à gauche de la requête.

      Vous en pouvez dupliquer que des requêtes simples et pour lesquelles vous avez des droits d'édition.

  3. Quelle que soit l'option que vous avez choisie, la démarche à suivre pour la construction de votre requête est quasiment la même, la seule différence résidant dans le volume d'information que vous devrez définir. Cliquez sur les liens disponibles dans les panneaux gauches des pages ou utilisez les boutons de navigation afin de vous déplacer tout au long du processus de conception de votre requête. De cette manière, vous pourrez :
    • Ajouter ou supprimer des champs. Pour en savoir plus, reportez-vous à : Comment sélectionner les champs
    • Trier les champs. Pour en savoir plus, reportez-vous à : Comment trier les champs
    • Définir un filtre. Pour en savoir plus, reportez-vous à : Comment filtrer les données
    • Trier les données résultant de l'exécution de la requête. Pour en savoir plus, reportez-vous à : Comment trier les données
    • Regrouper les résultats par champs. Pour en savoir plus, reportez-vous à : Comment regrouper les résultats par champs
    • Totaliser les résultats par champs. Pour en savoir plus, reportez-vous à : Comment définir les totaux
    • Établir le format d'affichage et de sortie des résultats de la requête. Pour en savoir plus, reportez-vous à : Comment définir le format de sortie de la requête
