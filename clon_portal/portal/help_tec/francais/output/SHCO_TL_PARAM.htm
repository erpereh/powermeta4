Options de session

Dans la page Options de session, vous personnalisez la représentation de l'information dans PeopleNet souhaitée pour vos sessions de travail. Dans le menu principal, sélectionnez l'option Outils | Options de session dans la barre de menus déroulants. La fenêtre Options de session apparaît.

Vous pouvez paramétrer les quatre options suivantes :

  • Format de date : utilisez cette option pour définir le format selon lequel vous voulez faire apparaître les valeurs de date au cours de votre session de travail.
  • Feuille de styles : utilisez cette option pour affecter une feuille de styles à votre session de travail. Les feuilles de styles déterminent l'apparence des pages dans l'application, en particulier les couleurs, les icones, les polices, etc.
  • Masquer les messages d'avertissement/d'information : vous pouvez opter pour masquer les messages d'avertissement et d'information émis par PeopleNet. C'est le cas par exemple quand vous voulez supprimer un enregistrement de la base de données : un avertissement apparaît d'abord pour vous demander de confirmer votre décision. Cette option vous permet de supprimer ce type d'avertissement.
  • Confirmer l'enregistrement lors de la navigation : dans les pages comprenant plusieurs formulaires (appelées assistants), certains boutons vous permettent d'enregistrer les données et de naviguer vers les autres formulaires (ou étapes) de l'assistant. Si vous activez cette option, des avertissements apparaissent pour vous prévenir du risque de perdre des données. Cela se produit quand des données sont erronées ou quand vous essayez de vous déplacer d'un formulaire vers un autre sans avoir pris le soin d'enregistrer auparavant les données modifiées. Si vous n'activez pas cette option, vous risquez de perdre des données dans de tels cas de figure.

Quand vous avez terminé de définir les options de session, cliquez sur le bouton Enregistrer : pour rendre effectives les nouvelles valeurs, vous devez obligatoirement quitter l'application et y entrer à nouveau. Pour ce faire, cliquez sur le bouton Déconnexion situé dans l'angle supérieur droit de la page.
