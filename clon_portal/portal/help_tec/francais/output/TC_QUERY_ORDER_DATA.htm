Comment trier les données

Objet

Une autre possibilité offerte par l'application est de trier les données résultant de l'exécution de la requête. De cette façon, vous pouvez ordonner les données en fonction de différents champs (jusqu'à cinq) et d'un ordre croissant ou décroissant.

Démarche à suivre

Procédez comme suit :

  1. Dans la page Trier les données, sélectionnez le champ qui sera trié en premier. Indiquez l'ordre de tri (croissant ou décroissant). Répétez l'opération au cas où vous souhaiteriez trier les données ensuite selon d'autres champs.
  2. Cliquez sur les flèches de navigation ou sur les étapes suivantes afin de continuer la construction de votre requête.
