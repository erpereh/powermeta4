Comment regrouper les résultats par champs

Objet

Vous pouvez définir des critères de regroupement des données générées par votre requête. Les regroupements s'effectuent à partir des champs sélectionnés pour la requête. De cette manière, les enregistrements sont affichés en groupes homogènes pour lesquels le champ désigné comme critère de regroupement présente la même valeur. La création de groupes permet le dénombrement des enregistrements de chaque groupe ou encore de calculer la valeur maximale, la valeur minimale ou la somme d'un champ différent de celui défini comme critère de regroupement.

Démarche à suivre

Procédez comme suit :

  1. Dans la page Regrouper les champs, sélectionnez le champ servant de premier critère de regroupement (le plus général). Vous pouvez ensuite indiquer d'autres critères (cinq au maximum) pour des sous-regroupements à l'intérieur des groupes de premier niveau.
  2. Cliquez sur les flèches de navigation ou sur les étapes suivantes afin de continuer la construction de votre requête.
