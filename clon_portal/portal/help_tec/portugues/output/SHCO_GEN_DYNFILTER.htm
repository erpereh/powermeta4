Filtro dinâmico

Finalidade

Neste formulário pode estabelecer a informação necessária para executar um filtro dinâmico ou em execução.

O processo é o seguinte:

  • Indica sobre que nó pretende aplicar o filtro na lista Critérios.

    • Dado um Meta4Object listam-se emCritériosos nós associados que tenham filtro dinâmico. Para cada um destes nós pode-se estabelecer uma instrução através do filtro HTML.

    Quando se acede ao filtro dinâmico da ligação Filtro avançado de alguma lista não se geram os critérios uma vez que o filtro se aplica sobre o nó ou tabela com a qual se está a trabalhar.

  • Seleccione o cenário sobre o qual pretende trabalhar no momento de filtrar.

    • Apenas aparecem listados aqueles cenários cuja tabela base coincida com a tabela base do nó cujo filtro estamos a editar. Se não realizar esta selecção, trabalha-se com a tabela base do nó.


  • Define as condições de filtragem que pretende estabelecer. Para tal, dispõe das seguintes opções:
    • Escrever o filtro directamente através do botão Filtro.

      • Para mais informação sobre como editar o filtro Html consulte Definição do filtro Html


    • Utilizar um filtro definido previamente clicando no botão Filtros predefinidos. Mostra-se a lista de filtros que desenhou anteriormente com o seu utilizador e para o cenário seleccionado ou se não tiver indicado cenário para a tabela base associada ao nó. Seleccione o filtro que pretende aplicar. Automaticamente regressa à página principal de edição do filtro dinâmico. Para mais informação, Definição de filtros predefinidos.

      • Na caixa de texto inferior aparece o texto do filtro desenhado ou seleccionado entre os predefinidos.

  • Grave o filtro sobre o nó clicando no botão Gravar .
  • Repita o processo para cada nó que pretenda filtrar.
  • Aplique o filtro de forma global ao Meta4Object clicando no botão Aplicar filtro .
