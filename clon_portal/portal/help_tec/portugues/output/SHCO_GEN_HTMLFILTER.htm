Definição do filtro Html

Finalidade

Neste formulário pode estabelecer os detalhes necessários para executar um filtro Html.

Acções

O filtro Html permite realizar pesquisas do cliente web seleccionando os critérios que pretende no interface do utilizador, e permite configurar e criar critérios complexos no ambiente web baseando-se em qualquer tabela.

O processo é o seguinte:

  1. Registe de forma obrigatória o ID Detalhe.
  2. Seleccione se em relação ao critério o devem cumprir todos os registos ou só algum.
  3. Seleccione a tabela e o campo da tabela ao qual se aplica o critério que vai estabelecer.
  4. Indique o tipo de relação que terá com outra tabela, campo ou valor.
  5. Seleccione:
    • Tabela/Campo no caso de pretender que o critério se relacione com outra tabela e o campo. Para tal, tem campos desdobráveis que se carregam com os dados correspondentes.
    • Valor no caso de pretender que o campo tenha um determinado valor.
  6. Seleccione o tipo de conexão no caso de pretender estabelecer mais critérios de filtro para um mesmo campo.
  7. Clique no botão Estabelecer detalhe . O Detalhe aparecerá na parte inferior da página. Se pretender modificar algum dado pode editá-lo através do botão Editar .
  8. Repita o processo para cada um dos critérios de filtragem.
  9. Quando tiver terminado com a definição de todos os detalhes, se pretender gravar as alterações clique no botão Gravar. Pergunta se pretende gravar o filtro como predefinido. Em caso afirmativo indica um nome para o filtro predefinido e aceita. Ou se não pretender defini-lo como predefinido clique no botão Cancelar. Para mais informação, Definição de filtros predefinidos.

    10. Clique no botão Aplicar filtro para continuar com o desenho do filtro dinâmico. Se aplicar as modificações sem gravar o filtro não tem a opção de gravar o filtro como predefinido.
