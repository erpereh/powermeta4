Lista de tarefas

Finalidade

A página Lista de tarefas contém todas as tarefas atribuídas por si e as que lhe foram atribuídas como parte de um processo de fluxo de trabalho. Utilize esta página para aceder directamente ao desenvolvimento das tarefas atribuídas; pode ver, modificar ou eliminar as suas tarefas pessoais.

  • Tarefas atribuídas

    • Se se definir em PeopleNet Ksystem um fluxo de trabalho para facilitar um processo, podem-se atribuir automaticamente ao utilizador tarefas como parte do fluxo do processo. Essas tarefas vão aparecer na lista Tarefas atribuídas. O utilizador não pode modificar a definição da tarefa mas pode, na página Lista de tarefas, clicar no botão Executar correspondente para levá-la a cabo.

  • Lista de tarefas pessoais

As tarefas pessoais são as definidas pelo próprio utilizador. Este pode definir determinadas tarefas que terá de desenvolver através de PeopleNet ou simplesmente através de avisos de trabalho. As tarefas pessoais podem ser geridas da seguinte forma:

  • Realizar uma tarefa: se a tarefa definida for um processo realizado através de PeopleNet, clique no botão correspondente a essa tarefa. Abre-se a página onde pode começar a desenvolver a tarefa.
  • Modificar a definição de uma tarefa: para modificar a definição de uma tarefa, clique no nome da mesma dentro da tabela Tarefas pessoais. Abre-se a página Gestão de tarefas pessoais, onde pode modificar as características e a descrição da tarefa. Para mais informação, Como modificar uma tarefa pessoal existente.
  • Eliminar uma tarefa: para eliminar uma tarefa da lista Tarefas pessoais, clique no botão Eliminar, correspondente a essa tarefa.
