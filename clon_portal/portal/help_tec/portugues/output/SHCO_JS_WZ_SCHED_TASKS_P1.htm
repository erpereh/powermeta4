Planificador de tarefas

Finalidade

Neste formulário descrevem-se os passos a seguir para configurar a planificação de uma tarefa.

A tarefa pode ser considerada como um modelo preparado que serve de ponto de partida para definir um trabalho ou tarefa de grupo. Trata-se de um código LN4 com um conjunto de parâmetros que não têm um valor definido. Uma vez atribuídos os valores a estes parâmetros, a tarefa converte-se numa tarefa do grupo propriamente dita. A finalidade das tarefas é reduzir o tempo de criação das tarefas do grupo.

O Planificador de tarefas evita a repetição de certas tarefas. Com ele pode definir uma série de tarefas para executá-las em diferido num determinado momento ou sempre que se cumpram certas condições temporais.

O Planificador de tarefas permite gerir todos os processos relacionados com a criação e manutenção de tarefas diferidas no tempo.

Acções

Através desta janela pode tanto inserir uma nova tarefa no sistema como editar os dados de outra já existente.

Para tal, siga os seguintes processos e recomendações:

  1. Clique no botão Novo para planificar uma nova tarefa ou filtre pelo código identificativo da tarefa ou pelo nome, grupo de tarefas ou utilizador de execução para editar uma tarefa planificada previamente. Também tem a opção de filtrar pelos estados:
    • Finalizado: recupera os grupos de tarefas cujas execuções planificadas se tenham finalizado. Isto é, relaciona os grupos de tarefas que não tenham nenhuma execução com estado Esperando, Em execução, Cancelando, Abortando.
    • Iniciado: recupera os grupos de tarefas onde se iniciaram alguma das execuções mas não se executaram todas. Considera execuções que ainda não se executaram, aquelas que têm estado: Esperando, Em execução, Cancelando, Abortando.
    • Não iniciado: recupera os grupos de tarefas cujas execuções ainda não se tenham iniciado. Concretamente, mostra os grupos cujas execuções estejam em estado Esperando.

      • Clique no botão . Registe de forma obrigatória o Grupo de tarefa e o ID Tarefa, nome e código identificativo da tarefa.


      O grupo de tarefas é uma sucessão de tarefas do grupo que são executadas através de uma determinada ordem. Quando se define um grupo de tarefas, atribui-se um nome, um código identificativo, uma descrição, uns parâmetros e, posteriormente, atribuem-se valores a estes parâmetros. Indica-se a tarefa que faz parte do grupo e define-se a data de execução, que é determinada por regras temporais.


  2. Seleccione de forma obrigatória as opções de Regras de tempo, isto é, indique as regras temporais que determinam o momento de execução do grupo de tarefas:
    • Imediato, vai-se executar quando seja possível.
    • Cíclico, onde deverá indicar uma data de início a partir da qual se executará o grupo de tarefas em intervalos regulares e estabelecer o número de vezes que se vai executar o grupo, que, no modo cíclico, nunca poderá ultrapassar 500 vezes. Para esta opção:
      • estabeleça o número de vezes que se vai executar o grupo. O conteúdo da opção Até vai-se actualizar automaticamente dependendo do número de execuções que se introduzir.
      • Até: se activar esta opção, em vez de estabelecer um número de execuções, deverá indicar a data e hora limite para executar o grupo. O número de vezes que se poderá executar mudará em função da data de início e da periodicidade estabelecidas.
    • Lista de datas: pode criar uma lista de datas para executar o grupo. Fixa-se o dia e a hora de execução. Há um quadro de texto para se inserir as datas. Para geri-lo tem os botões Acrescentar, Eliminar seleccionada e Eliminar todas. As datas inseridas têm que ser sempre posteriores ao momento actual.

      • Quando tiver seleccionado o modo de execução, para terminar a definição das regras de tempo, registe de forma obrigatória:

    • ID Fuso horário: menu desdobrável onde deve seleccionar o fuso horário que se utilizará para determinar o momento de execução do grupo.
    • Caduca depois de: quadro de grupo onde se define a caducidade que se aplicará a cada execução; assim, se passado o tempo especificado não tiver iniciado a execução do grupo, já não se iniciará. O tempo indica-se em minutos.
  3. Registe de forma optativa:
    • Descrição do grupo para aclarar a sua finalidade.
    • Sociedade, sobre a qual se vão executar as tarefas, no caso de estar a trabalhar num ambiente multi-sociedade.

      • No momento de seleccionar a sociedade, pode optar pela execução do grupo de tarefas para uma única sociedade; se, pelo contrário, fizer uma selecção múltipla, vão-se gerar tantos grupos de tarefas quantas as sociedades que tiver seleccionado.


  4. Clique nos links ou utilize os botões de navegação desta página para completar a configuração. Assim poderá inserir informação em relação a:
    • Opções avançadas. Para mais informação: Como definir as opções avançadas.
    • Parâmetros. Para mais informação: Como estabelecer os parâmetros da planificação.
    • Execuções. Para mais informação: Como consultar o estado das execuções.
