Como modificar uma tarefa pessoal existente

Finalidade

Utilize a página Gestão de tarefas pessoais para editar todas as tarefas pessoais. Para mais informação, Como definir uma nova tarefa pessoal.

Passos

  1. No menu principal, seleccione a opção Ferramentas | Editar tarefas pessoais. Abre-se a página Tarefas pessoais.
  2. Seleccione uma tarefa da lista para editá-la. Abre-se a página Gestão de tarefas pessoais, que inclui os detalhes da tarefa seleccionada.
  3. Reveja e modifique as características da tarefa, incluindo o nome, a data, hora de aviso e a descrição.
  4. Clique no botão Gravar.
  5. Se a tarefa estiver associada a um processo de aplicação, clique no link Parâmetros para que se abra o formulário Parâmetros.
  6. As tarefas pessoais que são apenas avisos não estão associadas a um processo de PeopleNet. Assim, não necessitam parâmetros.
  7. Reveja e modifique os parâmetros específicos da tarefa. Quando terminar a modificação dos valores, clique no botão Gravar.
