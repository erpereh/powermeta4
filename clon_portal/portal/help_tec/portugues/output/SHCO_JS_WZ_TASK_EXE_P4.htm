Finalidade

Este formulário permite ver os documentos gerados para uma determinada execução.

Mostram-se os documentos gerados como resultado da execução da tarefa seleccionada. A informação que se mostra de cada documento é:

  • Tamanho do documento associado.
  • Descrição do documento.
  • Recurso ou nome do documento associado.
