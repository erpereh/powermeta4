Como registar as opções de dispositivo

Finalidade

Este formulário permite-lhe definir as opções de dispositivo para os formatos de saída PCL, PostScript ou ESCP, no caso de terem sido seleccionados no passo anterior. Se tiver seleccionado outro tipo de formato de saída, as opções deste formulário aparecem desabilitadas.

Passos

O processo é o seguinte:

  • Se o formato de saída for PCL ou PostScript:
    1. Seleccione o tipo de tabuleiro.
    2. Indique se é frente e verso: desactivado, emulado ou real.
    3. Estabeleça o número de cópias.
    4. Especifique se girar a página.
    5. Seleccione a resolução.
    6. Seleccione a cor.
    7. Clique nos links ou utilize os botões de navegação desta página para completar a configuração.
  • Se o formato de saída for ESCP:
    1. Indique se é frente e verso: desactivado ou emulado.
    2. Estabeleça o avanço de linha.
    3. Indica o Factor X.
    4. Clique nos links ou utilize os botões de navegação desta página para completar a configuração.
