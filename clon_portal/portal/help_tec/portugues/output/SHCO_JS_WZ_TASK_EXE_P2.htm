Parâmetros de execução

Finalidade

Este formulário permite aplicar certos parâmetros à execução de uma tarefa.

Passos

O processo é o seguinte:

  1. Seleccione o parâmetro a aplicar, clicando no botão .
  2. O valor do parâmetro aparece na parte superior.
  3. Clique nos links ou utilize os botões de navegação desta página para continuar a navegação.
