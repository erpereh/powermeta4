Como estabelecer os parâmetros da planificação

Finalidade

Este formulário permite atribuir valores aos parâmetros da tarefa que compõem o grupo.

Passos

O processo é o seguinte:

  1. Para editar um registo clique no botão e para criar um novo, registe de forma obrigatória:
    • ID e nome da Tarefa
    • Parâmetro
  2. Registe de forma optativa:
    • Valor de parâmetro.
  3. Clique nos botões de navegação desta página para gravar as opções.
