Como definir as opções avançadas

Finalidade

Neste formulário define-se a moeda, o idioma e o role que se deve empregar na execução do grupo. Por defeito, utilizam-se os valores da sessão actual, mas pode alterá-los utilizando os quadros de lista, onde aparecem os diversos valores que se podem seleccionar para cada elemento.

Passos

O processo é o seguinte:

  1. Registe de forma obrigatória:
    • Role de execução
    • ID Prioridade
    • Moeda
    • Linguagem
  2. Registe de forma optativa:
    • Fila de execução
  3. Clique nos links ou utilize os botões de navegação desta página para completar a configuração.
