Como registar as opções avançadas

Finalidade

Este formulário permite-lhe estabelecer as opções de configuração de moeda se necessário.

Passos

O processo é o seguinte:

  1. Active a caixaEstabelecer moeda.
  2. Seleccione:
    • o ID da moeda
    • o tipo de câmbio
    • a data de câmbio
  3. Continue o processo utilizando os botões de navegação.
