Editar tarefas pessoais

Há três formas de aceder à página Gestão de tarefas pessoais, onde pode modificar a definição de uma tarefa pessoal existente.

  • Na página de menus principal de PeopleNet, clique para seleccionar uma tarefa do quadro Tarefas, situado à esquerda da página.
  • Seleccione Tarefas - Lista de tarefas. Na Lista de tarefas pessoais, clique no nome da tarefa para abrir a página Gestão de tarefas pessoais.
  • Seleccione Ferramentas - Modificar tarefas pessoais. No quadro de filtro, seleccione uma tarefa pessoal existente para abrir a página Gestão de tarefas pessoais.

Na página Gestão de tarefas pessoais, pode levar a cabo os seguintes processos:

  • Como modificar uma tarefa pessoal existente
  • Como definir uma nova tarefa pessoal
