Como configurar a saída de um relatório

Finalidade

Neste formulário descrevem-se os passos a seguir para configurar a execução ou planificação de um relatório.

Acções

Desta opção há duas possibilidades:

  • Executar um relatório directamente. Para tal, seleccionam-se as opções necessárias e executa-se o relatório.
  • Planificar a execução do relatório. Determinar o momento em que se executará o relatório.

    • Para ver os resultados da planificação da execução de um relatório deve consultar a opção Execuções do Planificador de tarefas. Para mais informação, Como consultar o estado de uma execução.


Para facilitar a inserção de parâmetros, o sistema permite-lhe visualizar uma janela com a maioria das opções de configuração. Esta janela de configuração divide-se em 3 passos.

No primeiro passo, Tipo e formato de saída, o procedimento que deve seguir é o seguinte:

  1. Seleccione o tipo de execução.
  2. Seleccione o tipo de saída. As possibilidades são as seguintes:
    • Visualização: permite a visualização do relatório no navegador.
    • Ficheiro em máquina cliente: o resultado da execução grava-se na máquina cliente.

      • O sistema apresentará uma caixa de diálogo que vai permitir gravar o ficheiro na localização desejada do disco local.

    • Ficheiro em servidor: o ficheiro resultado da execução armazena-se no sistema de ficheiros do servidor.

      • Para tal, deve introduzir o Caminho do directório temporário de relatórios do servidor onde se vai guardar o relatório.

    • Impressora em máquina cliente: impressão do relatório através de uma impressora da máquina cliente.

      • O sistema mostrará uma lista combinada para que seleccione a impressora.

    • Impressora em servidor: impressão através de uma impressora do servidor.

      • Se o tipo de saída escolhido for Impressora em servidor, o sistema mostra a lista de impressoras disponíveis e, após seleccionar uma, estabelece o idioma por defeito associado à impressora escolhida.


      No caso da planificação de relatórios os únicos tipos de saída permitidos são Ficheiro em servidor e Impressão em servidor. O resto das opções vão estar desabilitadas.


  3. Seleccione o formato de saída. Os formatos permitidos variam em função do tipo de saída seleccionado no passo anterior:
    • HTML: permitidos para a visualização e o ficheiro em servidor.
    • PDF: permitido para as opções de visualização e ficheiro tanto na máquina cliente como no servidor.
    • Texto: este formato pode-se utilizar em qualquer caso.
    • PCL: permitido em qualquer tipo de saída excepto visualização.
    • ESCP: permitido em qualquer tipo de saída excepto visualização.
    • PostScript: permitido em qualquer tipo de saída excepto visualização.
  4. Clique nos links ou utilize os botões de navegação desta página para completar a configuração. Assim poderá inserir informação em relação a:
    • Opções de dispositivo. Mais informação: Como registar as opções de dispositivo
    • Opções avançadas. Mais informação: Como registar as opções avançadas
