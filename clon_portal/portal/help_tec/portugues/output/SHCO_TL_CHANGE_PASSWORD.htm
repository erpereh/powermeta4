Alterar a password de conexão

Finalidade

Para alterar a password associada ao ID de conexão, use a opção Alteração de password, no menu desdobrável Ferramentas. Se dispuser de dois ID de conexão, apenas poderá alterar a password associada ao que estiver a utilizar na sessão actual.

Passos

  1. No menu principal, seleccione a opção Ferramentas | Alteração de password. Abre-se a página Altere a password. Aparece automaticamente o ID de conexão actual.
  2. Escreva a sua password actual.
  3. A seguir, escreva nos campos correspondentes a nova password e volte a escrever para confirmá-la.
  4. Clique no botão Gravar.
