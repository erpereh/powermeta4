Como definir uma nova tarefa pessoal

Finalidade

Utilize a página Gestão de tarefas pessoais para editar todas as tarefas pessoais.

Para mais informação, Como modificar uma tarefa pessoal existente.

Passos

  1. No menu principal, seleccione a opção Ferramentas | Editar tarefas pessoais. Abre-se a página Tarefas pessoais.
  2. Clique no botão Novo. Abre-se a página Gestão de tarefas pessoais.
  3. Introduza as características da tarefa, incluindo o nome, a data, hora de aviso e a descrição.
  4. Clique no botão Gravar.
  5. Se a tarefa estiver associada a um processo de aplicação, clique no link Parâmetros para que se abra o formulário Parâmetros.
  6. Insira valores para os parâmetros específicos da tarefa. Quando tiver terminado, clique no botão Gravar.
