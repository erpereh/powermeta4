Cómo registrar las opciones de dispositivo

Finalidad

Este formulario te permite definir las opciones de dispositivo para los formatos de salida PCL, PostScript o ESCP, en el caso de que se hayan seleccionado en el paso anterior. Si hubiera seleccionado otro tipo de formato de salida, las opciones de este formulario aparecen deshabilitadas.

Pasos

El proceso es el siguiente:

  • Si el formato de salida es PCL o PostScript:
    1. Selecciona el tipo de bandeja.
    2. Indica si es a doble cara: desactivado, emulado o real.
    3. Establece el número de copias.
    4. Especifica si girar la página.
    5. Selecciona la resolución.
    6. Selecciona el color.
    7. Haz clic en los enlaces o utiliza los botones de navegación de esta página para completar la configuración.
  • Si el formato de salida es ESCP:
    1. Indica si es a doble cara: desactivado o emulado.
    2. Establece el avance de línea.
    3. Indica el Factor X.
    4. Haz clic en los enlaces o utiliza los botones de navegación de esta página para completar la configuración.
