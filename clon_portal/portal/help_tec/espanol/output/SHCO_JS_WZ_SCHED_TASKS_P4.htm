Cómo definir las opciones avanzadas

Finalidad

En este formulario se definen la moneda, el idioma y el rol que se deben emplear en la ejecución del grupo. Por defecto se utilizan los valores de la sesión actual, pero puede cambiarlos utilizando los cuadros de lista, en los que se muestran los distintos valores que se pueden seleccionar para cada elemento.

Pasos

El proceso es el siguiente:

  1. Registra de manera obligatoria:
    • Rol de ejecución
    • ID Prioridad
    • Moneda
    • Lenguaje
  2. Registra de manera opcional:
    • Cola de ejecución
  3. Haz clic en los enlaces o utiliza los botones de navegación de esta página para completar la configuración.
