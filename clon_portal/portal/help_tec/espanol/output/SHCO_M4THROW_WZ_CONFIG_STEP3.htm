Cómo registrar las opciones avanzadas

Finalidad

Este formulario te permite establecer las opciones de configuración de moneda en caso necesario.

Pasos

El proceso es el siguiente:

  1. Activa la casilla Establecer moneda.
  2. Selecciona:
    • el ID de la moneda
    • el tipo de cambio
    • la fecha de cambio
  3. Continúa el proceso utilizando los botones de navegación.
