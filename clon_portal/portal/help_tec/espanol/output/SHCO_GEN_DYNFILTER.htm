Filtro dinámico

Finalidad

En este formulario puedes establecer la información necesaria para ejecutar un filtro dinámico o en ejecución.

El proceso es el siguiente:

  • Indica sobre nodo quieres aplicar el filtro en la lista Criterios.

    • Dado un Meta4Object se listan en Criterios los nodos asociados que tengan filtro dinámico. Para cada uno de estos nodos se puede establecer una sentencia a través del filtro HTML.

    Cuando accedes al filtro dinámico desde el enlace Filtro avanzado de alguna lista no se generan los criterios puesto que el filtro se aplica sobre el nodo o tabla con la que estás trabajando.

  • Selecciona el escenario sobre el que quieres trabajar a la hora de filtrar.

    • Sólo aparecen listados aquellos escenarios cuya tabla base coincida con la tabla base del nodo cuyo filtro estamos editando. Si no realizas esta selección, se trabaja con la tabla base del nodo.


  • Define las condiciones de filtrado que deseas establecer. Para ello, tienes las siguientes opciones:
    • Escribir el filtro directamente a través del botón Filtro.

      • Para más información sobre cómo editar el filtro Html consulta Definición del filtro Html


    • Utilizar un filtro definido previamente haciendo clic en el botón Filtros predefinidos. Se muestra la lista de filtros que has diseñado anteriormente con tu usuario y para el escenario seleccionado o si no has indicado escenario para la tabla base asociada al nodo. Selecciona el filtro que deseas aplicar. Automáticamente regresas a la página principal de edición del filtro dinámico. Más información, Definición de filtros predefinidos

      • En la caja de texto inferior aparece el texto del filtro diseñado o seleccionado entre los predefinidos.

  • Guarda el filtro sobre el nodo haciendo clic en el botón Guardar .
  • Repite el proceso para cada nodo que quiera filtrar.
  • Aplica el filtro de forma global al Meta4Object haciendo clic en el botón Aplicar filtro .
