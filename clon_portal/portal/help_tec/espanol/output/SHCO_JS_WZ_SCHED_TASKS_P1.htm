Planificador de tareas

Finalidad

En este formulario describe los pasos que se tienen que seguir para configurar la planificación de una tarea.

La tarea se puede considerar como un modelo preparado que sirve de punto de partida para definir un trabajo o tarea de grupo. Se trata de una pieza de código LN4 con un conjunto de parámetros que no tienen un valor definido. Una vez asignados los valores a estos parámetros, la tarea se convierte en una tarea del grupo propiamente dicha. La finalidad de las tareas es reducir el tiempo de creación de las tareas del grupo.

El Planificador de tareas evita la repetición de ciertas tareas. Con él se puede definir una serie de tareas para ejecutarlas en diferido en un momento dado o siempre que se cumplan ciertas condiciones temporales.

El Planificador de tareas permite gestionar todos los procesos relacionados con la creación y el mantenimiento de las tareas diferidas.

Acciones

Desde esta pantalla puedes tanto introducir una nueva tarea en el sistema como editar los datos relativos a otra que ya forme parte de él.

Para ello sigue estos procesos y recomendaciones:

  1. Haz clic en el botón Nuevo para planificar una nueva tarea o filtra por el código identificativo de la tarea o el nombre, grupo de tareas o usuario de ejecución para editar una tarea planificada previamente. También tienes la opción de filtrar por los estados:
    • Finalizado: recupera los grupos de tareas cuyas ejecuciones planificadas hayan finalizado. Es decir, relaciona los grupos de tareas que no tengan ninguna ejecución con estado Esperando, En ejecución, Cancelando, Abortando.
    • Iniciado: recupera los grupos de tareas de los que se haya iniciado alguna de las ejecuciones pero no se hayan terminado de ejecutar todas. Considera ejecuciones que aún no se han ejecutado aquellas que tienen estado: Esperando, En ejecución, Cancelando, Abortando.
    • No iniciado: recupera los grupos de tareas cuyas ejecuciones todavía no se hayan iniciado. Concretamente, muestra los grupos cuyas ejecuciones estén en estado Esperando.

      • Haz clic en el botón . Registra de manera obligatoria el Grupo de tarea y el ID Tarea, nombre y código identificativo de la tarea.


      El grupo de tareas es una sucesión de tareas del grupo que se ejecutan en un orden concreto. Cuando se define un grupo de tareas, se le asigna un nombre, un código identificativo, una descripción, unos parámetros y, posteriormente, se asignan valores a estos parámetros. Se indica la tarea que forma parte del grupo, así como la fecha en la que ha de ejecutarse, la cual queda determinada por las reglas temporales.


  2. Selecciona de forma obligatoria las opciones de Reglas de tiempo, es decir, indica las reglas temporales que determinan cuándo se ejecutará el grupo de tareas:
    • Inmediato, se ejecutará en cuanto sea posible.
    • Cíclico, para lo que deberás indicar una fecha de comienzo a partir de la cual se ejecutará el grupo de tareas a intervalos regulares y establecer el número de veces que se va a ejecutar el grupo, que en el modo cíclico nunca podrá superar las 500. Para esta opción:
      • establece el número de veces que se ejecutará el grupo. El contenido de la opción Hasta se actualizará automáticamente en función del número de ejecuciones que se introduzca.
      • Hasta: si activas esta opción, en lugar de establecer un número de ejecuciones, deberás indicar la fecha y hora límite hasta las que se podrá ejecutar el grupo. El número de veces que se podrá ejecutar cambiará en función de la fecha de inicio y la periodicidad establecidas.
    • Lista de fechas: puedes crear una lista de fechas en las que debe ejecutarse el grupo. Se fija el día y la hora de ejecución. Existe un cuadro de texto en el que se introducen las fechas. Para gestionarlo tienes los botones Añadir, Borrar seleccionada y Borrar todas. Las fechas introducidas siempre tienen que ser posteriores al momento actual.

      • Una vez que se ha seleccionado el modo de ejecución, para terminar de definir las reglas de tiempo, registra de forma obligatoria:

    • ID Franja horaria: menú desplegable en el que debes seleccionar la zona horaria que se utilizará para determinar el momento de ejecución del grupo.
    • Expira después de: cuadro de grupo en el que se define la expiración que se aplicará a cada ejecución; así, si pasado el tiempo especificado no se ha iniciado la ejecución del grupo, ya no se iniciará. El tiempo se indica en minutos.
  3. Registra de manera opcional:
    • Descripción del grupo para aclarar su finalidad.
    • Sociedad, sobre la que se van a ejecutar las tareas, en el caso de que esté trabajando en un entorno multisociedad.

      • A la hora de seleccionar la sociedad, puedes optar por que la ejecución del grupo de tareas sea para una única sociedad; si, por el contrario, hace una selección múltiple, se generarán tantos grupos de tareas como sociedades haya seleccionado.


  4. Haz clic en los enlaces o utiliza los botones de navegación de esta página para completar la configuración. Así podrás introducir información relativa a:
    • Opciones avanzadas. Más información: Cómo definir las opciones avanzadas.
    • Parámetros. Más información: Cómo establecer los parámetros de la planificación.
    • Ejecuciones. Más información: Cómo consultar el estado de las ejecuciones.
