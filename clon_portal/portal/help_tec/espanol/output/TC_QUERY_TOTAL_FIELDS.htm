Cómo establecer totalizaciones

Finalidad

Para cada grupo de datos, definidos en el apartado anterior, es posible contar el número de registros o calcular el máximo, el mínimo, la media o la suma de un campo distinto al fijado como criterio de agrupación. También puedes definir estas operaciones para todos los datos aunque no estén agrupados.

Pasos

El proceso es el siguiente:

  1. Desde Totalizar campos, se muestran todos los campos seleccionados en tu consulta y la indicación de las operaciones que puedes realizar con ellos. Aquellas operaciones que no puedas realizar para cada campo no están disponibles. Estas restricciones se establecen en función del tipo de cada campo.

    2. Marca la operación que deseas realizar para cada campo.

  2. Haz clic en las flechas de navegación o en los pasos siguientes para continuar el diseño.
