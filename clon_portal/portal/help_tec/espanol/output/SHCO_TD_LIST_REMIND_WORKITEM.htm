Editar tareas personales

Hay tres maneras de obtener acceso a la página Gestión de tareas personales, en la que puede modificar la definición de una tarea personal existente.

  • En la página de menús principal de PeopleNet, haz clic para seleccionar una tarea del cuadro Tareas, situado a la izquierda de la página.
  • Elija Tareas - Lista de tareas. Dentro de la Lista de tareas personales, haz clic en el nombre de la tarea para abrir la página Gestión de tareas personales.
  • Elija Herramientas - Modificar tareas personales. En el cuadro de filtro, selecciona una tarea personal existente para abrir la página Gestión de tareas personales.

En la página Gestión de tareas personales, puede llevar a cabo los siguientes procesos:

  • Cómo modificar una tarea personal existente
  • Cómo definir una nueva tarea personal
