Herramientas

Utiliza las opciones del menú Herramientas para mejorar las sesiones de trabajo, así como para personalizar la apariencia y comportamiento de la aplicación.

  • Consulta, modifica o borra las tareas mediante Lista de tareas.
  • Agrega, modifica o borra las tareas mediante Editar tareas personales.
  • Cambia la contraseña de su ID de conexión actual. Más información, Cambiar la contraseña de conexión.
  • Personaliza el comportamiento de la aplicación para sus sesiones de trabajo. Más información, Personalizar las opciones de la sesión de trabajo.
  • Planifica aquellas tareas rutinarias que debes realizar periódicamente con el objetivo de ahorrar tiempo y buscar la eficiencia. Más información, Planificador de tareas.
  • Consulta la cola de tus ejecuciones y el estado en el que se encuentra. Más información, Cómo consultar el estado de las ejecuciones.
