Cómo configurar la salida de un informe

Finalidad

En este formulario se describen los pasos que se tienen que seguir para configurar la ejecución o planificación de un informe.

Acciones

Desde esta opción tienes dos posibilidades:

  • Ejecutar un informe directamente. Para ello se seleccionan las opciones necesarias y se ejecuta el informe.
  • Planificar la ejecución del informe. Determinar el momento en que se ejecutará el informe.

    • Para ver los resultados de la planificación de la ejecución de un informe debe consultar la opción Ejecuciones del Planificador de tareas. Más información, Cómo consultar el estado de una ejecución.


Para facilitar la introducción de parámetros, el sistema te permite visualizar una ventana con la mayoría de las opciones de configuración. Esta ventana de configuración está dividida en 3 pasos.

En el primer paso, Tipo y formato de salida, el procedimiento que debes seguir es el siguiente:

  1. Selecciona el tipo de ejecución.
  2. Selecciona el tipo de salida. Las posibilidades son las siguientes:
    • Visualización: permite la visualización del informe en el navegador.
    • Archivo en máquina cliente: el resultado de la ejecución se guarda en la máquina cliente.

      • El sistema presentará un caja de diálogo que permitirá guardar el archivo en la ubicación deseada del disco local.

    • Archivo en servidor: el archivo resultado de la ejecución se almacena en el sistema de archivos del servidor.

      • Para ello, debes introducir la Ruta relativa al directorio temporal de informes del servidor donde se guardará el informe.

    • Impresora en máquina cliente: impresión del informe a través de una impresora de la máquina cliente.

      • El sistema mostrará una lista combinada para que seleccionas la impresora.

    • Impresora en servidor: impresión a través de una impresora del servidor.

      • Si el tipo de salida elegido es Impresora en servidor, el sistema muestra la lista de impresoras disponibles y, una vez seleccionada una, establece el idioma por defecto asociado a la impresora elegida.


      En el caso de la planificación de informes los únicos tipos de salida permitidos son Archivo en servidor e Impresión en servidor. El resto de opciones estarán deshabilitadas.


  3. Selecciona el formato de salida. Los formatos permitidos varían en función del tipo de salida seleccionado en el paso anterior:
    • HTML: permitidos para la visualización y el archivo en servidor.
    • PDF: permitido para las opciones de visualización y archivo tanto en máquina cliente como en servidor.
    • Texto: este formato se puede utilizar en cualquier caso.
    • PCL: permitido en cualquier tipo de salida excepto visualización.
    • ESCP: permitido en cualquier tipo de salida excepto visualización.
    • PostScript: permitido en cualquier tipo de salida excepto visualización.
  4. Haz clic en los enlaces o utiliza los botones de navegación de esta página para completar la configuración. Así podrás introducir información relativa a:
    • Opciones de dispositivo. Más información: Cómo registrar las opciones de dispositivo
    • Opciones avanzadas. Más información: Cómo registrar las opciones avanzadas
