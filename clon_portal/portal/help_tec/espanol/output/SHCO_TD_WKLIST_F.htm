Lista de tareas

Finalidad

La página Lista de tareas refleja todas las tareas que se le han asignado como parte de un proceso de flujo de trabajo o que se ha asignado usted mismo. Utiliza esta página para obtener acceso directo al desarrollo de las tareas que tiene asignadas; puede ver, modificar o borrar sus tareas personales.

  • Tareas asignadas

    • Si en PeopleNet Ksystem se define un flujo de trabajo para facilitar un proceso, se le podrán asignar automáticamente al usuario unas tareas como parte del flujo del proceso. Dichas tareas aparecerán en la lista Tareas asignadas. El usuario no puede modificar la definición de la tarea pero sí puede, dentro de la página Lista de tareas, hacer clic en el botón Ejecutar correspondiente para llevarla a cabo.

  • Lista de tareas personales

Las tareas personales son las que define el propio usuario. Éste puede definir tareas determinadas que ha de desarrollar mediante PeopleNet o simplemente recordatorios de trabajo. Se pueden gestionar las tareas personales de las siguientes maneras:

  • Realizar una tarea: si la tarea definida es un proceso realizado mediante PeopleNet, haz clic en el botón correspondiente a dicha tarea. Se abre la página en la que puede empezar a desarrollar la tarea.
  • Modificar la definición de una tarea: para modificar la definición de una tarea, haz clic en el nombre de la misma dentro de la tabla Tareas personales. Se abre la página Gestionar tareas personales, en la que puede modificar las características y la descripción de la tarea. Para más información, Cómo modificar una tarea personal existente.
  • Borrar una tarea: para eliminar una tarea de la lista Tareas personales, haz clic en el botón Borrar correspondiente a dicha tarea.
