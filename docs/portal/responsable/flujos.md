# Recorridos del responsable

## Alcance del responsable y delegaciones

El SSM permite consultar y gestionar personas dentro de un alcance autorizado, con tipos de responsabilidad y delegaciones. El [manual, PDF 68](../referencias/manuales.md#tareas-y-alcance-del-responsable), distingue UO de responsabilidad directa, dependientes, posiciones, un árbol activo por tipo de responsabilidad y excepciones de revisión salarial. La selección de población para consultas no es el alcance de aprobaciones.
