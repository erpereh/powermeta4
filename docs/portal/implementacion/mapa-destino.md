# Correspondencia original → `/portal`

Todos los destinos son **propuestas** para implementaciones posteriores. No se han creado rutas de aplicación. El grupo privado será `src/app/(app)/portal/`. Las matrices del inventario asignan cada ruta técnica a su dominio; la tabla siguiente agrupa esas piezas en pantallas y flujos públicos. Un include, script, controlador, wrapper, traducción o backup se integra como dependencia, no como una página nueva.

Los subdestinos abreviados en la tabla pertenecen al prefijo indicado, no a la raíz del sitio. Se pueden ajustar segmentos al implementar, manteniendo una correspondencia explícita y enlaces desde el índice. Formularios cortos pueden ser diálogos; asistentes o detalles extensos, subrutas.

La selección de variante se realiza por contexto operativo y NAE verificado (P09). El mismo destino funcional puede mostrar diferencias legítimas por sociedad. No copiar cuatro árboles de componentes completos para cada personalización.
