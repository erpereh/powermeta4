# Dependencias del servidor del portal

> Generado por `npm run portal:docs` desde `src/lib/portal/registry`. No editar a mano.

Cada fila es una operación que powermeta4 **no ejecuta**: el formulario se muestra completo
y validado, pero el envío queda deshabilitado con su método Meta4 hasta que exista un
servicio publicado y una aprobación de escritura (AGENTS.md solo aprueba el alta de personas).

## Pendientes

| ID  | Qué falta                                                                                                           |
| --- | ------------------------------------------------------------------------------------------------------------------- |
| P01 | Publicación por sociedad y perfil: Falta el menú efectivo del servidor que confirme qué pantalla usa cada sociedad. |
| P02 | Metadatos y reglas del objeto Meta4: Faltan la definición de nodos, ítems, catálogos y reglas internas del objeto.  |
| P03 | Identidad y autorización: Falta verificar el vínculo con el empleado o el alcance del responsable.                  |
| P04 | Contrato de escritura: No hay un servicio publicado ni autorización para ejecutar esta operación desde powermeta4.  |
| P05 | Comprobación en ejecución: Falta contrastar la pantalla con el portal real y una sesión de cada perfil.             |
| P06 | Dependencia dinámica: El original carga un recurso que solo resuelve el servidor.                                   |
| P07 | Módulo de otra generación: La función pertenece a otra interfaz o módulo cuyo uso real no está confirmado.          |
| P08 | Distribución de documentos: Falta el servicio real del documento, su formato y sus permisos.                        |
| P09 | Variante por sociedad: Falta confirmar la variante que aplica a la sociedad.                                        |
