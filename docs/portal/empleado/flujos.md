# Recorridos del empleado

Cada guía describe las pantallas como un flujo funcional. Su índice técnico conserva los campos, atributos, llamadas y variantes de todas las páginas asociadas. La identidad del empleado propio y las operaciones ERP siguen pendientes de integración server-side.

| Dominio                                                                 | Guía de comportamiento               | Inventario técnico               |
| ----------------------------------------------------------------------- | ------------------------------------ | -------------------------------- |
| Organización, directorio y organigramas                                 | [Organización](organizacion/guia.md) | [Índice](organizacion/README.md) |
| Datos personales, currículo, IRPF, contactos, dependientes y documentos | [Datos](datos/guia.md)               | [Índice](datos/README.md)        |
| Bancos, nómina, certificados, préstamos, beneficios y proyecciones      | [Retribución](retribucion/guia.md)   | [Índice](retribucion/README.md)  |
| Puesto, formación, evaluación, carrera y movilidad                      | [Talento](talento/guia.md)           | [Índice](talento/README.md)      |
| Vacaciones, incidencias, ausencias, festivos y GTA                      | [Tiempo](tiempo/guia.md)             | [Índice](tiempo/README.md)       |
| Conocimiento                                                            | [Conocimiento](conocimiento/guia.md) | [Índice](conocimiento/README.md) |

Antes de un formulario, leer [contratos comunes](../transversal/contratos.md); antes de una consulta de otra persona o un documento, leer [integración](../implementacion/integracion-powermeta4.md). Los botones y campos visibles no prueban permiso de lectura o escritura.
